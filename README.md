# AWF - Akeeba Web Framework

A tiny MVC web application framework for single source standalone web applications, and WordPress plugins.

## Regulatory status (EU Cyber Resilience Act)

Akeeba Web Framework is not monetized and is not placed on the market within the meaning of Regulation (EU) 2024/2847; Akeeba Ltd acts as its open-source software steward under Article 24 of that Regulation.
